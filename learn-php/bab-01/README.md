# Bab 01 — Program pertama

PHP dapat menjalankan skrip langsung dari terminal. `echo` menulis teks ke output standar.

## Baca dan jalankan

Dari direktori `learn-php/bab-01`, jalankan:

```sh
php main.php
```

Keluaran yang diharapkan:

```text
layanan pesanan siap
```

## Latihan mandiri

Tambahkan baris `mode lokal`, lalu jalankan lagi dan pastikan kedua pesan muncul berurutan.
