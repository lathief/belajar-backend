# Bab 03 — Kondisi dan perulangan

`foreach` mengunjungi setiap nilai array. Kondisi `if` memilih jumlah yang memenuhi batas bisnis.

## Baca dan jalankan

```sh
php main.php
```

Keluaran yang diharapkan:

```text
jumlah_diterima=2
```

## Telusuri program

Hanya jumlah dari 1 sampai 5 yang diterima; nilai lainnya tidak menambah penghitung.

## Latihan mandiri

Tambahkan jumlah `5` ke array dan periksa bahwa penghitung berubah.
