# Bab 02 — Variabel, tipe, dan operator

Variabel PHP diawali `$`. Konversi eksplisit dengan ` (int)` membuat teks `"2"` menjadi angka sebelum dipakai menghitung.

## Baca dan jalankan

```sh
php main.php
```

Keluaran yang diharapkan:

```text
subtotal=15000
```

## Telusuri program

Harga satuan adalah 5.000. Jumlah teks dikonversi ke integer lalu ditambah satu, sehingga subtotalnya 5.000 × 3.

## Latihan mandiri

Ubah jumlah awal menjadi `"4"` dan prediksi subtotal baru.
