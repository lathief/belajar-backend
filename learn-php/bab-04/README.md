# Bab 04 — Fungsi dan nilai balik

Fungsi bernama mengemas aturan agar dapat dipakai kembali. Deklarasi tipe parameter dan tipe balik membantu memperjelas kontraknya.

## Baca dan jalankan

```sh
php main.php
```

Keluaran yang diharapkan:

```text
total=12000
```

## Telusuri program

`hitungTotal` menerima harga dan jumlah sebagai integer, lalu mengembalikan hasil perkalian. `echo` hanya menangani presentasi.

## Latihan mandiri

Ubah jumlah menjadi `3` dan periksa nilai total.
