# Bab 01 — Program pertama

JDK menyediakan perintah `java` dan `javac`. Saat menjalankan `java Main.java`, Java mengompilasi berkas sumber lalu memanggil `main`. `static` membuat method dapat dipanggil tanpa membuat objek `Main`, sedangkan `void` berarti method selesai tanpa mengembalikan nilai.

## Baca dan jalankan

Buka [Main.java](Main.java). Dari direktori `learn-java/bab-01`, jalankan perintah berikut.

```sh
java Main.java
```

Keluaran program yang diharapkan

```text
layanan pesanan siap
```

## Telusuri program

`String[] args` disiapkan untuk argumen terminal. `System.out` adalah tujuan keluaran standar. Tanda titik mengakses anggota dan tanda kurung memanggil method.

## Latihan mandiri

Cetak `mode lokal` pada baris kedua. Coba hilangkan satu titik koma, baca lokasi kesalahan, lalu perbaiki.
