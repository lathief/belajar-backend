# Bab 04 — Method dan parameter

Tipe sebelum nama method menentukan tipe hasil. Parameter memiliki tipe dan hanya dapat diakses di dalam method tersebut. `return` mengirim nilai ke pemanggil. Pemanggilan dari `main` memisahkan penggunaan aturan harga dari definisinya.

## Baca dan jalankan

Buka [Main.java](Main.java). Dari direktori `learn-java/bab-04`, jalankan perintah berikut.

```sh
java Main.java
```

Keluaran program yang diharapkan

```text
total=15000
```

## Telusuri program

Perhatikan tiga tempat yang memakai `int` pada deklarasi `subtotal`. Dua di antaranya menentukan apa yang masuk dan satu menentukan apa yang keluar.

## Latihan mandiri

Tambahkan parameter diskon tetap. Panggil dengan harga 5000, jumlah 3, dan diskon 2000. Hasil harus 13000.
