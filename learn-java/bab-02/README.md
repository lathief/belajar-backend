# Bab 02 — Variabel, tipe, dan operator

`int` menyimpan bilangan bulat, `boolean` menyimpan kondisi, dan `String` menyimpan teks. `final` membatasi pengisian variabel menjadi satu kali. Perkalian dihitung sebelum hasil digabung dengan teks.

## Baca dan jalankan

Buka [Main.java](Main.java). Dari direktori `learn-java/bab-02`, jalankan perintah berikut.

```sh
java Main.java
```

Keluaran program yang diharapkan

```text
subtotal=15000
```

## Telusuri program

Ekspresi `harga * jumlah` menghasilkan angka 15000. Operator `+` yang bersebelahan dengan string kemudian menggabungkan teks dan angka tersebut.

## Latihan mandiri

Ubah jumlah awal menjadi 3. Total setelah penambahan satu unit harus menjadi 20000. Coba ubah harga setelah deklarasi `final` dan baca diagnosis compiler.
