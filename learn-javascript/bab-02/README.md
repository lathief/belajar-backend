# Bab 02 — Variabel, tipe, dan konversi

Gunakan `const` untuk binding yang cukup diisi sekali dan `let` untuk nilai yang akan diisi ulang. Argumen dan input pengguna sering berupa string. `Number()` mengonversi teks sebelum operasi aritmetika. Template literal menyisipkan nilai melalui `${...}`.

## Baca dan jalankan

Buka [main.mjs](main.mjs). Dari direktori `learn-javascript/bab-02`, jalankan perintah berikut.

```sh
node main.mjs
```

Keluaran program yang diharapkan

```text
subtotal=15000
```

## Telusuri program

Dengan konversi, `2 + 1` menjadi angka 3. Jika konversi dihapus, string `"2"` ditambah angka 1 menjadi string `"21"`. Perkalian berikutnya mengubah string itu menjadi angka lagi.

## Latihan mandiri

Ganti input menjadi `3`. Prediksi hasilnya, lalu hilangkan `Number()` dan amati akibat `+=` pada string sebelum mengembalikannya.
