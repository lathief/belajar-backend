# Bab 01 — Program pertama di Node.js

Node.js menjalankan JavaScript di terminal. Ekstensi `.mjs` mengaktifkan format ES module. Program kecil ini mulai dari pernyataan pertama dan `console.log` mengirim teks ke keluaran standar.

## Baca dan jalankan

Buka [main.mjs](main.mjs). Dari direktori `learn-javascript/bab-01`, jalankan perintah berikut.

```sh
node main.mjs
```

Keluaran program yang diharapkan

```text
layanan pesanan siap
```

## Telusuri program

Tanda titik pada `console.log` mengakses fungsi `log` milik `console`. Isi tanda kurung diberikan sebagai argumen. Baris `//` adalah catatan untuk pembaca.

## Latihan mandiri

Tambahkan baris `mode lokal`. Jalankan dari terminal dan periksa bahwa kedua pesan muncul berurutan.
