# Bab 04 — Fungsi dan scope

`function` mendefinisikan perilaku bernama. Parameter dan `const` yang dibuat dalam fungsi hanya tersedia di lingkupnya. `return` menyerahkan hasil ke pemanggil. Satu fungsi dapat dipakai oleh beberapa pemanggil tanpa mengulang rumus.

## Baca dan jalankan

Buka [main.mjs](main.mjs). Dari direktori `learn-javascript/bab-04`, jalankan perintah berikut.

```sh
node main.mjs
```

Keluaran program yang diharapkan

```text
total=15000
```

## Telusuri program

Angka 5000 dan 3 dipasangkan menurut posisi parameter. Hasil 15000 menggantikan ekspresi pemanggilan fungsi di dalam template literal.

## Latihan mandiri

Tambahkan parameter diskon dengan nilai default 0. Panggil dengan dan tanpa diskon 1000. Hasil harus 14000 dan 15000.
