# Bab 02 — Variabel, tipe, dan operator

Tipe mendahului nama variabel. `int` cocok untuk jumlah barang dan `decimal` dapat merepresentasikan pecahan desimal seperti harga. Sufiks `m` membentuk literal `decimal`. Interpolasi string memakai `$` dan ekspresi di dalam kurung kurawal.

## Baca dan jalankan

Buka [Program.cs](Program.cs). Dari direktori `learn-c-sharp/bab-02`, jalankan perintah berikut.

```sh
dotnet run --file Program.cs
```

Keluaran program yang diharapkan

```text
subtotal=15000
```

## Telusuri program

Setelah `jumlah` menjadi 3, perkalian menghasilkan `decimal`. Tanda `{}` dalam string interpolasi mencetak hasil ekspresi tersebut.

## Latihan mandiri

Ubah jumlah awal menjadi 3. Setelah ditambah satu unit, subtotal harus menjadi 20000.
