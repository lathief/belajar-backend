# Belajar Programming

Kumpulan materi belajar pemrograman backend berbahasa Indonesia. Setiap folder memiliki roadmap dan contoh yang dijalankan dari terminal. Materi bahasa pemrograman menggunakan kasus pesanan yang mirip agar konsepnya mudah dibandingkan; folder Docker berfokus pada praktik container.

## Pilih jalur belajar

| Folder | Fokus | Persiapan utama |
| --- | --- | --- |
| [learn-c-sharp](learn-c-sharp/README.md) | C# untuk backend, dari dasar hingga studi kasus expert | .NET SDK 10 atau lebih baru |
| [learn-docker](learn-docker/README.md) | Image, container, jaringan, volume, Compose, dan layanan Go | Docker Desktop dengan Linux containers |
| [learn-go](learn-go/README.md) | Go untuk backend, pola sistem, serta contoh layanan HTTP | Go |
| [learn-java](learn-java/README.md) | Java untuk backend, dari dasar hingga studi kasus expert | JDK 21 |
| [learn-javascript](learn-javascript/README.md) | JavaScript di Node.js, termasuk modul dan operasi async | Node.js 22 atau lebih baru |
| [learn-php](learn-php/README.md) | PHP CLI, pemodelan domain, dan pola backend | PHP 8.2 atau lebih baru |
| [learn-rust](learn-rust/README.md) | Rust untuk backend, dari ownership hingga studi kasus expert | Rust stable 1.85 atau lebih baru |

Sebagian besar jalur bahasa memiliki 18 bab: dasar, intermediate, advanced, lalu expert. Jalur Docker memiliki 9 bab praktik. Baca README di folder yang dipilih untuk roadmap rinci dan instruksi versi/perintah.

## Mulai

1. Pasang prasyarat untuk jalur pilihan Anda.
2. Buka README folder bahasa atau topik tersebut.
3. Jalankan perintah dari direktori bab yang ditunjukkan README bab.
4. Prediksi output, jalankan contoh, lalu kerjakan latihan mandiri.

Setiap jalur berdiri sendiri; tidak ada satu setup atau perintah yang menjalankan seluruh materi sekaligus. Contoh Bab 09 pada jalur bahasa memproses argumen terminal menjadi rekap pesanan.

## Catatan

Contoh studi kasus tingkat lanjut adalah model pembelajaran, bukan implementasi siap produksi. Sistem nyata memerlukan penyimpanan persisten, transaksi, validasi operasional, dan pengujian sesuai kebutuhan.
